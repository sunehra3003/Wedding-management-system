# Wedding Planner Web App

A full-featured wedding management web application built with Node.js and Supabase, helping clients plan their perfect wedding by selecting venues, salon packages, florists, decorators, and bakeries — all in one place.

---

##  Features

###  Client
- Browse and customize wedding packages
- Select and book venues
- Choose salon, florist, bakery, and decorator services
- Track and manage wedding planning in one place

###  Admin
- Manage all orders and bookings
- Add and manage florists, venues, salons, bakeries, and decorators
- Full control over service listings and availability

### Venue Manager
- View all venue booking requests
- Accept or reject bookings
- Manage venue availability and scheduling

##  Database Setup

1. Create a new project on [Supabase](https://supabase.com)
2. Restore using the provided backup file via **Database → Backups**
3. Or import the provided CSV files via **Table Editor → Import CSV**

---

##  Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/wedding-planner.git
```

2. Install dependencies:
```bash
npm install
```

4. Start the server:
```bash
node app.js
```

5. Open your browser and go to:
```
http://localhost:3000
```
